# Toy Plane Arcade: Support

**Report a problem or ask a question:** email st72365@gmail.com (we reply within a few days), or open an issue at https://github.com/SumantxD/toy-plane-sim/issues.

**Report a player:** email st72365@gmail.com with the pilot name, the room code if you have it, and what happened.

## Common questions

**How do I play with friends?** On the home screen tap FRIENDS, then HOST ONLINE. Send your friends the 5-letter room code; they tap FRIENDS, type it under "Join a friend" and tap JOIN.

**A room code won't connect.** Some mobile networks block direct connections. Try Wi-Fi, or see "If a room code won't connect" in How to Play.

**LAN or online play won't connect on iPhone.** Make sure Local Network access is on for Toy Plane Arcade: Settings > Privacy & Security > Local Network.

**I bought something and don't see it.** Bought looks are worn automatically and listed in HANGAR (home screen). If one is missing, open SHOP and tap RESTORE PURCHASES, signed in with the same Apple ID you bought with.

**Refunds.** In-app purchases are refunded by Apple: https://reportaproblem.apple.com

**Do purchases make my plane stronger?** No. Everything in the Shop is looks only.
